Migrar de Bootstrap a Tailwind CSS

Aprende las diferencias entre Bootstrap y Tailwind CSS, y cómo migrar tus proyectos de una forma eficiente y manteniendo el mismo aspecto visual.

Objetivos Diferencias Conversión Ejercicios Proyecto

1 Objetivos de la Clase

✓ Comprender Diferencias

Entender las diferencias fundamentales entre Bootstrap y Tailwind CSS.

✓ Convertir Estilos

Convertir estilos de Bootstrap a clases utilitarias de Tailwind.

✓ Configurar Tailwind

Configurar tailwind.config.js para personalizar colores y tipografías.

✓ Migrar Proyecto

Aplicar los conocimientos migrando un proyecto completo.

2 Diferencias Principales

Bootstrap Tailwind CSS
Usa clases predefinidas (ej. btn-primary, card) Usa clases utilitarias (bg-blue-500, p-4)
Depende de archivos CSS externos No necesita un archivo CSS adicional
Grid basado en row, col-* Grid basado en grid, flex
Requiere modificar CSS Personalización con tailwind.config.js
Componentes más pesados Más ligero, optimizado
Componentes más pesados Más ligero, optimizado

3 Conversión de Clases Comunes

Bootstrap Tailwind Descripción
container mx-auto px-4 Contenedor
row flex flex-wrap Fila
col-md-6 md:w-1/2 Columna
btn px-4 py-2 rounded Botón
card shadow-lg rounded-lg Tarjeta
text-center text-center Centrar

Configuración Tailwind

Para personalizar Tailwind CSS, edita el archivo tailwind.config.js:

tailwind.config.js

module.exports = {
  content: ["./src/**/*.{html,js}"],
  theme: {
    extend: {
      colors: {
        primary: "#1e3a8a",
        secondary: "#64748b",
      },
      fontFamily: {
        sans: ['Inter', 'sans-serif'],
      },
    },
  },
  plugins: [],
}

index.html (con CDN)

<script>
  tailwind.config = {
    theme: {
      extend: {
        colors: {
          clifford: '#da373d',
        }
      }
    }
  }
</script>

<p class="bg-clifford text-white p-2 rounded">
  Texto de prueba
</p>
