Conceptos Fundamentales

¿Qué es Tailwind CSS?

Es un framework CSS que se basa en clases utilitarias para diseñar interfaces de usuario rápidamente sin escribir CSS personalizado.

Filosofía Utility-First

  • ✓ Usa clases pequeñas y reutilizables
  • ✓ Evita la sobreespecificidad
  • ✓ Soluciona problemas con la cascada de estilos
  • ✓ Desarrollo más rápido y eficiente

Instalación y Configuración

Opción 1: CDN

La forma más rápida para proyectos pequeños o pruebas.

<script src="https://cdn.tailwindcss.com"></script>

✓ Ventajas:

  • • Sin instalación requerida
  • • Perfecto para prototipos
  • • Listo para usar inmediatamente

Opción 2: PostCSS

Configuración profesional para proyectos grandes.

npm install -D tailwindcss
npx tailwindcss init

✓ Ventajas:

  • • Personalizable completamente
  • • Optimizado para producción
  • • Mejor para proyectos grandes

Configuración PostCSS (tailwind.config.js)

module.exports = {
  content: ["./src/**/*.{html,js}"],
  theme: {
    extend: {},
  },
  plugins: [],
};

Archivo CSS (style.css)

@tailwind base;
@tailwind components;
@tailwind utilities;

Clases Utilitarias Principales

Espaciado

(margin, padding)

m-4 - margin
p-6 - padding
mx-auto - centrar
gap-4 - espacios

Tipografía

(text, font, leading)

text-3xl - tamaño
font-bold - peso
text-center - alineación
leading-relaxed - altura

Colores

(bg, text, border)

bg-blue-500 - fondo
text-white - texto
border-gray-300 - borde
rounded-lg - esquinas

¿Por Qué Usar Tailwind?

⚡

Desarrollo Rápido

Crea interfaces en minutos sin escribir CSS personalizado.

🎨

Diseño Consistente

Sistema de colores y espaciado predefinido mantiene coherencia.

📱

Responsive por Defecto

Diseño móvil-primero con prefijos de punto de quiebre.

🛠️

Personalizable

Configuración completa de colores, tipografía y más.

📦

Archivo Optimizado

Solo incluye el CSS que realmente usas en tu proyecto.

🌍

Comunidad Activa

Amplia comunidad con recursos, plugins y componentes.

Consejos Prácticos

✓ Empieza con CDN

Usa la versión CDN para aprender y prototipar rápidamente.

✓ Usa Componentes

Crea componentes reutilizables para mantener tu código limpio.

✓ Mobile-First

Diseña primero para móvil, luego amplía para pantallas grandes.

✓ Personaliza el Tema

Configura tu paleta de colores y fuentes en tailwind.config.js.

✓ Aprende las Clases

Memoriza las clases más comunes para acelerar tu flujo de trabajo.

✓ Documentación

Consulta la documentación oficial para descubrir nuevas funciones.
